# Velo-CE · Layout dell'etichetta articolo per scatola, Code 39 (prova)

## Riassunto

Layout Word di prova dell'etichetta articolo da applicare a scatole e colli in magazzino: codice articolo in chiaro e in Code 39, descrizione, data e ora di stampa. La regola stampata è "un collo, un codice", con lettura tramite lettore Code 39 o app Business Central.

## Punti chiave

- Campi: codice articolo (`No_`, anche in Code 39), descrizione, data e ora di stampa.
- Pensata per la lettura con lettore barcode o con l'app mobile di Business Central.
- Variante per magazzino dell'etichetta articolo standard ([[velo-ce-layout-etichetta-articolo-standard-report-6625-interno]]).

## Numeri

- Barcode Code 39 sul codice articolo.

## Decisioni e azioni

- Nessuna decisione nel documento: è un layout di prova, senza indicazioni su quale etichetta verrà adottata.
