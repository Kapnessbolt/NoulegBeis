# Qricambi

## Chi sono

- Fornisce ai ricambisti prezzi e disponibilità dei fornitori via API; sviluppa da tre anni Quoting24.com, un'idea simile a Parts Radar ([[integrazione-api-qricambi-proposta-di-collaborazione]])

## Relazione con BlueAge

- BlueAge vuole integrarne le API per prezzi netti e disponibilità; il primo pilota è già utente Qricambi. Qricambi non si considera concorrente ma chiede di non ricevere dettagli confidenziali ([[integrazione-api-qricambi-proposta-di-collaborazione]])
- Call sull'integrazione del 05/10/2026, organizzata da Cristian Schifone ([[integrazione-api-qricambi]])
- Esito: le API si possono integrare in Parts Radar, ma l'accesso lo deve chiedere il ricambista, cliente diretto di Qricambi; la documentazione delle API è già disponibile ([[2026-10-22-watermark-e-task-schedulati]])
